# IA e reconhecimento de fala

Área para experimentos reproduzíveis de reconhecimento de fala em português e, se viável, inferência local.

Antes de escolher modelos, registrar:
- modelo e versão;
- tamanho em disco e RAM de pico;
- latência por áudio;
- uso de CPU e temperatura;
- qualidade em ambiente silencioso e com ruído;
- comportamento quando o modelo não entende o comando.

A Orange Pi H618 com 2 GB ainda precisa ser benchmarkada. Não assumir que executará LLM com latência aceitável.
